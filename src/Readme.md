# 📚 The Book Haven

The Book Haven is a full-stack digital library web application where users can explore, add, update, and manage books easily. Users can authenticate securely, view detailed book information, and manage their own book collection dynamically.

---

## 🌐 Live Website

🔗 Live Site: https://benevolent-maamoul-294a57.netlify.app/

---

## 🚀 Features

- 🔐 Firebase Authentication with Email/Password & Google Login
- 📖 Add, Update, Delete, and Manage Personal Books
- ⭐ Rating-based Sorting System
- 💬 Real-time Comment Section on Book Details Page
- 📱 Fully Responsive for Mobile, Tablet, and Desktop
- 🔒 Protected Private Routes
- ⚡ Dynamic Latest Books Section from MongoDB
- 🍞 Toast Notifications using React Hot Toast
